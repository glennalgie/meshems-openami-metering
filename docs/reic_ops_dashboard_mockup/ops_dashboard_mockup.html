What this is: a concept mockup of the live operations view Jude asked for on the REIC call - alarm status and contactor commands a non-engineer can read at a glance, instead of raw MQTT topics. Real data would come from openami/<deviceID>/subpanel_RCMleaks (AC/DC leakage mA, alarm flags) already published by the Street-EMS firmware; commands would publish back to the same broker. MPM Manager stays the system of record for customers and billing - this dashboard is the safety/alarm layer MPM doesn't cover, not a replacement for it. For review before anything gets wired up live.
